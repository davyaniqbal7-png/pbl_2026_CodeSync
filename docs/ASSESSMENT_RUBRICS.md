# Petunjuk Penggunaan

Dokumen ini berisi **rubrik penilaian Core Learning Artifacts (D1–D4), rubrik supporting evidence & individual evidence, rubrik per Sub-CPMK (individu), rubrik presentasi/Demo Day**, serta **bagan agregasi** untuk menghasilkan nilai akhir per sub-CPMK per mahasiswa (skala 0–100) dan **Individual Competency Passport**.

Mengacu `revision_note_1.md`:
- **Team Evidence** = Core Artifacts D1–D4 + product quality.
- **Individual Evidence** = Gate 1 oral defense, Gate 2 code walkthrough, individual reflection, contribution evidence, decision explanation.
- Proporsi default: **50% team artifact · 30% individual defense/walkthrough · 20% individual reflection/process evidence**.

Kerangka, prinsip, dan master generic attributes SFIA ada di `assessment_framework`. Rentang skor (default):

| Skala 4 | Rentang 0–100 | Tingkat kemahiran | Klaim level SFIA |
|---|---|---|---|
| Unggul | 85–100 | Mahir penuh | Klaim penuh |
| Memadai | 70–84 | Memadai | Klaim level |
| Berkembang | 55–69 | Berkembang | Penguatan, belum klaim |
| Belum | <55 | Belum | Belum tercapai / remedial |

**Skor tengah untuk agregasi**: Unggul = 92, Memadai = 77, Berkembang = 62, Belum = 45.

Dokumen ini untuk dosen & reviewer gate. Rubrik yang dibagikan ke mahasiswa adalah versi ringkas di [template_pack](TEMPLATE_PACK.md) dan project wall.

## 3) Rubrik Generic Attributes SFIA (Level 1: L1 vs L2)

Dipakai reviewer untuk klaim level individu (master lengkap L1–L4 di `assessment_framework` Bagian 7).

| Generic Attribute | Level 1 (Follow) | Level 2 (Assist) | Bukti pada project |
|---|---|---|---|

| Knowledge | Pengetahuan dasar; menerapkan pengetahuan baru untuk membangun skill | Aplikasi pengetahuan esensial; menyerap informasi baru sistematis | Penguasaan saat walkthrough & tanya jawab demo |
| Business Skills | Komunikasi cukup untuk dialog efektif; kerja terorganisir | Komunikasi efektif; kerja tim; menjadwalkan kerja sendiri | Meeting log, presentasi, ketepatan waktu deliverable |

## 8) Bagan Agregasi: Bukti → Sub-CPMK → Nilai Akhir → Passport

### 8.1 Mapping bukti → Sub-CPMK + bobot

Bobot di bawah default dan dapat diselaraskan RPS. Skor bukti memakai skala 0–100. Hanya Sub-CPMK pada Bagian 6.1 yang diagregasi.

| Sub-CPMK | Sumber Bukti (bobot) | Assessor |
|---|---|---|
| S-01.1 (I) | WS02–WS05 (20%) · D1 (30%) · D2 (30%) · Gate 1 defense (20%) | Dosen Konsep SI; reviewer gate |
| S-03.1 (I) | WS05–WS06 (25%) · D2 (50%) · Gate 1 defense (25%) | Dosen Konsep SI; reviewer gate |
| S-03.5 (I) | WS07, WS09–WS13 (25%) · D2 desain + D3 (35%) · Code walkthrough / Gate 2 (40%) | Dosen Dasar Prog; reviewer gate |
| S-14.1 (I) | WS01, WS14 (25%) · D4 (25%) · presentasi (30%) · peer assessment (20%) | Dosen Kom. Profesional |

Konversi ke CPMK/MK (default): **Konsep SI** = 50% S-01.1 (CPMK-01) + 50% S-03.1 (CPMK-03); **Dasar Pemrograman** = 100% S-03.5 (CPMK-03); **Komunikasi Profesional** = 100% S-14.1 (CPMK-14); **Bahasa Inggris** = rubrik bahasa D4 (tanpa Sub-CPMK).

### 8.2 Rumus agregasi

- **Skor bukti** (0–100): dari rubrik per core artifact (Bagian 2) atau rubrik komponen (Bagian 4–6).
- **Skor Sub-CPMK** = Σ (bobot bukti × skor bukti) / 100.
- **Skor CPMK** = Σ (bobot sub-CPMK × skor sub-CPMK) — bobot sub-CPMK ditetapkan level sesuai `06a_sub_cpmk_mapping`; dipakai untuk penilaian RPS tiap MK.
- **Klaim level SFIA**: sub-CPMK ≥ 70 (Memadai) pada bukti pendukung skill = klaim level target; 55–69 = penguatan; <55 = remedial.

### 8.3 Output akhir per mahasiswa

Score sheet per mahasiswa (template di `instructor_guide` Bagian 5.1) menghasilkan:
- nilai akhir per Sub-CPMK yang dinilai (0–100 + tingkat kemahiran) + catatan indikator formatif,
- nilai per CPMK (konversi ke MK),
- klaim level SFIA,
- **Individual Competency Passport** (9 kompetensi: problem framing, system thinking, computational thinking, programming, testing, communication, collaboration, AI literacy, reflection),
- status: lulus / remedial.

## 10) Catatan Penggunaan

- Rubrik dinilai **per individu** pada aspek Sub-CPMK; aspek produk kelompok (dimensi) dinilai tim, lalu kontribusi individu diverifikasi via walkthrough, log kontribusi, peer/self assessment, dan verifikasi silang reviewer.
- Proporsi 50/30/20 bersifat **default** (project_guide §6.2) dan dapat diselaraskan dengan RPS; jika diubah, perbarui seluruh rentang agar konsisten.
- Rubrik versi mahasiswa dibagikan di awal proyek (project wall & template_pack).
